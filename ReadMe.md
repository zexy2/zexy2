## About

I'm a Computer Engineering graduate from İzmir, focused on building full-stack web applications with a strong backend and data layer. I mostly work with **React / Next.js**, **Spring Boot / NestJS**, and **PostgreSQL / PostGIS**.

I care about projects that are practical, reviewable, and easy to run: clear setup, understandable architecture, meaningful commits, and enough documentation for another developer to evaluate the work without guessing.
