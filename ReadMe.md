## About

Computer Engineering graduate (Honours, GPA 3.46 / 4.00) based in İzmir, Turkey. I build products end to end: Next.js and React interfaces, NestJS and Spring Boot APIs, PostgreSQL data models, and Dockerized deployments behind Nginx on a VPS.

Most recently I spent five months at **Kafein Technology Solutions** on **FEYS**, Türk Telekom's enterprise operations platform for device, port, service, inventory and planning workflows. I delivered 47 of its 53 Next.js pages in a legacy modernization effort, implemented the Spring Boot mock backend across controller, service and repository layers, standardized response, error, validation and pagination contracts, and backed them with a 470-test JUnit 5 / Spring MockMvc suite and a 113-request Postman/Newman contract collection.

I care about work that can be reviewed rather than demonstrated once: stable API contracts, explicit error states, audit trails, and tests that prove the claim.
